# Research: возможность доставки в ПВЗ Wildberries

**Приоритет:** P3

## Контекст

В PDF есть отдельный исследовательский блок про возможность доставки в ПВЗ Wildberries. Это не задача на немедленную разработку, а отдельное исследование.

## Что найдено в проекте

- В коде нет интеграции с Wildberries.
- В текущем scope запуска магазина этот блок не пересекается с обязательной реализацией checkout.

## Что нужно сделать

1. Проверить, существует ли технический способ отправки заказов внешнего интернет-магазина в ПВЗ WB.
2. Изучить доступность API/партнёрской программы.
3. Собрать ограничения:
  - юридические;
  - финансовые;
  - логистические;
  - упаковка/маркировка;
  - выбор ПВЗ на стороне сайта.
4. Подготовить короткий вывод:
  - возможно;
  - невозможно;
  - возможно только при дополнительных условиях.
5. Если сценарий недоступен, предложить альтернативы.
